# ai-transition

我的 AI 转型记录：从一个跟代码不太沾边的岗位，转向能用 AI 做出东西的人。

这个仓库不追求好看，只追求**每天有东西进来**。

## 这里放什么

| 目录 | 内容 |
| --- | --- |
| `README.md` | 总入口：我在干什么、进度到哪 |
| `notes/` | 每天一条学习日志，写清楚学了什么、卡在哪、怎么解决的 |
| `scripts/` | 练习用的小脚本，跑得通就行，不要求优雅 |
| `projects/` | 攒够了就做成一个能跑的小项目 |
